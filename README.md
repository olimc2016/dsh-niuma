# dsh-niuma · 牛马加速器

[![npm](https://img.shields.io/npm/v/dsh-niuma.svg)](https://www.npmjs.com/package/dsh-niuma)

> DSH（DeepSeek Harness）插件：把**实收月薪**换算成**每秒跳动的现金计数器**。
> 上班摸鱼看一眼，今天的钱正在一秒一秒地长大；下班后它停住，提醒你「今天又白干了」还是「今天赚够了」。

## 它算什么

填一次你的情况，面板每秒更新：

- **今日已赚**：按秒累加的有效工作收益，4 位小数，肉眼可见地跳
- **秒工资 / 分工资 / 时工资 / 日工资 / 周工资 / 月工资** 六档换算
- **工作日口径**：周一至周五上班；**法定节假日不算工作日**；**调休上班日算工作日**
- 节假日不算工作日 → 当月工作日变少 → **日工资更高**（这正是「牛马加速器」的核心体感）
- **月度 / 全年视角**：可切换查看任意月份的实际工作日、日/时/分/秒工资；也能看**全年平均**（按年收入 ÷ 全年工作日）
- **全年假日最多的月份**会自动标出（2026 年是 2 月：春节 9 天法定假，当月只有 16 个工作日）
- 「今日已赚」金额用金色显示，深浅主题都醒目；金额统一以「元」为单位
- 单独的**节假日卡片**：2026 年（官方）与 **2027 年（预估，官方尚未公布）** 两段，含七个假日区段、天数、日期范围与调休统计
- 设置保存在 `$DSH_HOME/niuma/config.json`（原子写、0600 权限），不依赖 DSH 设置服务，重启后仍生效
- 节假日数据内置在插件中（2026 官方 / 2027 预估），设置区不再需要手工维护一长串日期；2027 官方安排公布后随插件更新
- 午休可设置起止，**可勾选午休是否算工时**；午休不算工时则午休期间金额冻结
- 状态徽标：休息日 / 未上班 / 搬砖中 / 午休中 / 已下班
- 主金额是**连续里程表滚动**：小数末位飞快转、前一位慢 10 倍、整数位慢慢进位；勾选「加速」按屏幕刷新率每帧滚动
- 主金额**小数位可选（0–6）**，右侧下拉即时生效
- **刷新频率可选**：按秒 / 250ms / 100ms / 50ms / 屏幕刷新率（≈16ms 连续滚动）
- 今日进度条、距上班/距下班倒计时
- **本月已工作 / 剩余工作日**（与工资口径一致：节假日、周末、调休都算进去）

### 口径公式

| 指标 | 公式 |
|---|---|
| 日有效工时 | （下班 − 上班）−（午休启用且不计薪 ? 午休时长 : 0） |
| 当月工作日数 | 当月内「周一至周五，扣除法定节假日，加上调休上班日」的天数 |
| 日工资 | 实收月薪 ÷ 当月工作日数 |
| 时工资 | 日工资 ÷ 日有效工时 |
| 分工资 / 秒工资 | 时工资 ÷ 60 / ÷ 3600 |
| 周工资 | 日工资 × 本周（周一~周日）工作日数 |
| 今日已赚 | 今日有效工作秒数 × 秒工资（封顶日工资） |

默认内置 **2026 年**法定节假日与调休上班日，来源：
[国务院办公厅关于2026年部分节假日安排的通知（国办发明电〔2025〕7号）](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)。
跨年后可在面板里直接编辑「节假日 / 调休上班日」（一行一个 `YYYY-MM-DD`）。

## 安装

```bash
# 在 DSH profile 里安装（包名：dsh-niuma）
dsh plugin --profile desktop add dsh-niuma
```

或写进 profile 的 `package.json` 依赖与 `dsh.profile.bundles` 后重启 DSH。
**插件是启动时加载的，安装/升级后必须完全退出并重开 DSH。**

## 使用

1. 打开 DSH 侧栏 → 点 **牛马** 图标
2. 展开「设置」：填实收月薪、上下班时间、午休时间，勾选午休是否算工时
3. 保存后回到顶部看「今日已赚」按秒滚动

## 隐私

- 不联网、不上传、不统计。工资、作息只存在你本机的 DSH 设置里。
- 面板所有数字（除了节假日表）都由本机时间实时计算。

## 兼容性

- DSH 0.2.x（开发与验证版本：0.2.1-rc.2）
- Node ≥ 22.19.0（DSH 自带运行时满足）

## 开发

```bash
npm run setup    # 链接 DSH 基座模块 + esbuild（只需一次）
npm run build    # 构建 lib/client.js（构建产物必须入库）
npm test         # 5 项自检：core / holidays / host 烟测 / client 烟测 / 渲染烟测
```

`lib/client.js` 是构建产物，源码在 `src/client/index.js`；宿主半侧在 `lib/index.js`，纯逻辑在 `src/core.mjs`。
实现契约与验收口径见 [`SPEC.md`](SPEC.md)。
